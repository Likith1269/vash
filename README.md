# Vash – Hyperlocal Laundry Service Platform

Vash is a web-based hyperlocal laundry service platform designed to
digitize local laundry operations and provide a convenient interface
for customers, administrators, and delivery riders.

## Project Overview

The goal of Vash is to simplify the interaction between customers
and local laundry services by providing a digital platform for
managing laundry-related operations.

The project includes separate interfaces and workflows for
customers, administrators, and riders.

## Key Features

- Customer registration and login
- Customer-facing laundry service interface
- Admin management interface
- Rider interface
- Responsive web design
- Firebase integration
- Web-based laundry service management
- Mobile-friendly interface

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Firebase
- Firebase Hosting

## User Roles

### Customer

Customers can access the platform and interact with the laundry
service workflow through the customer-facing interface.

### Admin

The admin interface is designed to support centralized management
of the platform and its operations.

### Rider

The rider interface is designed to support laundry pickup and
delivery operations.

## Project Objective

The objective of Vash is to bring local laundry services into a
digital platform and provide a structured system for managing
customers, laundry operations, and delivery activities.
